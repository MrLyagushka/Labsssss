ОПИСАНИЕ

Программа SetAliasDB v1.0 представляет собой консольное приложение для 
создания новых или изменения существующих псевдонимов баз данных в BDE.

формат командной строки запуска:

setaliasdb.exe <AliasName> <AliasPath>

где
 <AliasName> - псевдоним создоваемой или модифицируемой базы данных
 <AliasPath> - путь к базе данных 

Особенности работы программы:
 1. Программа выполняется только при наличии двух входных параметров 
    если задан один или параметров нет то программа завершает работу.
 2. Выполняется процедура проверки установлен ли BDE на компьютере.
    При отсутствии BDE программа завершает работу.
 3. Если в качестве пути к базе данных указана директория которая 
    не существует на данном компьютере то путь к базе данных 
    не изменяется в случае изменения существующего псевдонима и 
    псевдоним с заданным путем не создается в случае создания нового 
    псевдонима базы данных BDE.
 4. Если в BDE уже зарегистрировон псевдоним указанный в параметре
    <AliasName> то программа выполняет изменение пути к базе данных
    для данного псевдонима на <AliasPath>.
 5. Изменение параметров псевдонима происходит сразу после запуска
    программы с указанными параметрами без предварительного
    запроса на изменение или создание псевдонима.
 6. Программы работает без вывода на экран каких либо сообщений
    включая результат выполненной операции по изменению или 
    добавлению псевдонима.

Пример вызова программы:
 
  setaliasdb.exe MyAppDB c:\MyApp\db

Рекомендации по использовани: 
  
  Если необходимо создать или модифицировать несколько псевдонимов
  то удобно использовать BAT файл в который занести вызовы программы 
  с различными параметрами.

  Например создать файл setmyapp.bat в директории с программой 
  и внести в него следующии вызовы программы для создания сразу 
  трех псевдонимов баз данных
                      
      setaliasdb.exe MyAppDB1 c:\MyApp\db1
      setaliasdb.exe MyAppDB2 c:\MyApp\db2
      setaliasdb.exe MyAppDB3 c:\MyApp\db3
